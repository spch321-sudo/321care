# 321愛的關懷（321 Loving Care）

國度321空中團契 · 牧養關懷 PWA
**先生命 · 再關係 · 後事工**

按場景分享合適的經文與祝福，記錄生日與紀念日，陪伴每一位弟兄姊妹成為得勝者。

---

## 功能

| 分頁 | 內容 |
|---|---|
| 今日 | 近 30 天的生日／紀念日、本週建議關懷名單、逾 90 天未關懷提醒 |
| 羊群 | 名冊、235 關係標記（2 屬靈同伴／3 屬靈父母兒女／5 五重職份戰友）、關懷紀錄 |
| 卡片 | 25 個場景 × 每場景 10 張經文卡片，共 250 張；可做成圖卡分享到 LINE |
| 錄製 | 錄語音或自拍影片，合成經文卡影片 |
| 設定 | 署名、字級、配色、**介面語言**、行事曆匯出、備份與還原 |

**AI小智**：說明對象與情況，AI 會量身寫出合適的經文與問候（需另行架設後端代理）。

### 三種語言

- **繁體中文**：原生
- **简体中文**：由繁體即時逐字轉換，內容 100% 涵蓋
- **English**：另行翻譯的版本，經文採 World English Bible（公有領域）

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `321care`）。
2. 把本資料夾**所有檔案**上傳到 repository 根目錄。
3. 進入 **Settings → Pages**，Source 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是：
   `https://<你的帳號>.github.io/<repository 名稱>/`

### 檔案清單

```
index.html                 主程式（單檔，含全部程式與內容）
manifest.json              PWA 設定（App 名稱、圖示、顏色）
sw.js                      Service Worker（離線快取）
.nojekyll                  告訴 GitHub Pages 不要用 Jekyll 處理
README.md                  本說明

apple-touch-icon.png       iPhone 加到主畫面的圖示（180×180）
favicon.ico                瀏覽器分頁小圖示
icon-16/32/120/152/167/180.png   各尺寸圖示
icon-192.png               Android／PWA 圖示
icon-512.png               Android／PWA 圖示（大）
icon-1024.png              高解析原圖
icon-192-maskable.png      Android 自適應圖示（留安全區）
icon-512-maskable.png      Android 自適應圖示（大）
og-image.png               分享到 LINE／Facebook 時的預覽圖（1200×630）
```

## 每次更新後一定要做的事

改完 `index.html` 之後，**務必把 `sw.js` 第 4 行的版號往上跳**：

```js
const CACHE = "care321-v2.7.0";   // ← 改成 v1.4.1、v1.4.2 …
```

沒有跳版號，長輩的手機會一直開到舊版本。

### 長輩手機看不到新版時

1. 開 App → 設定 → 最下方「**強制更新到最新版**」
2. 若仍是舊版：長按主畫面圖示 → 移除 App → 用 Safari 重新開啟網址 → 分享 → 加入主畫面

## 隱私

所有名冊與關懷紀錄**只存在使用者自己的手機裡**（localStorage 與 IndexedDB），不會上傳到任何伺服器。牧養資料是弟兄姊妹的隱私，請妥善保管，並定期使用「備份全部資料」存檔。

## 321 理念

**三個基礎**：耶穌是我的榜樣、聖經是我的準則、聖靈是我的引導
**兩個核心**：讓耶穌作王、讓耶穌得著一切的榮耀
**一個目的**：建立屬神的體系

> 關懷不是去解決人的問題，是陪伴人回到耶穌面前。
